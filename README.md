Trang web CV cá nhân hoàn chỉnh, trực quan và hiện đại được xây dựng hoàn toàn bằng **HTML5, CSS3 và Vanilla JavaScript** (Single-file kiến trúc gọn nhẹ, hiệu năng cao, tối ưu SEO và sẵn sàng xuất bản).

---

## 🌟 Tính Năng Nổi Bật

- **Bố cục 2 cột (Desktop) & Responsive (Mobile/Tablet)**:
  - Cột trái: Sticky cố định hiển thị ảnh đại diện, thông tin cá nhân, liên hệ, nhóm kỹ năng (Tech Stack) và học vấn.
  - Cột phải: Cuộn nội dung Tóm tắt bản thân, Quá trình kinh nghiệm làm việc (Timeline dọc) và Lưới dự án nổi bật.
- **Chế độ Sáng / Tối (Light & Dark Mode)**:
  - Nút chuyển đổi nhanh ở góc màn hình.
  - Tự động ghi nhớ trạng thái người dùng bằng `localStorage` và tự phát hiện theme hệ thống (`prefers-color-scheme`).
- **Hiệu ứng Scroll Reveal**: Tự động trượt nhẹ và hiển thị nội dung khi người dùng cuộn chuột tới thông qua `IntersectionObserver`.
- **Micro-interactions**:
  - Click để sao chép nhanh Email & Số điện thoại kèm thông báo Toast notification mượt mà.
  - Hiệu ứng nổi thẻ (card hover) 3D nhẹ, shadow chuyển màu tinh tế.
  - Nút Back-to-top xuất hiện thông minh khi cuộn trang.
- **Tối ưu in ấn & Xuất PDF (`@media print`)**:
  - Tích hợp nút "Tải CV / In PDF" (`window.print()`).
  - Tự động ẩn các thành phần điều hướng, căn chuẩn khổ giấy A4 sạch sẽ, rõ nét phục vụ gửi nhà tuyển dụng.

## 🛠️ Công Nghệ Sử Dụng

- **Frontend**: HTML5 Semantic, CSS3 Modern (CSS Variables, Flexbox, Grid), Vanilla JavaScript (ES6+).
- **Typography & Icons**: Google Fonts (*Plus Jakarta Sans*), FontAwesome 6 CDN.
- **Dev Server**: `npx serve` hoặc bất kỳ static server nào.

## 🚀 Hướng Dẫn Chạy Thử Trên Máy

### Cách 1: Chạy trực tiếp
Nhấp đúp chuột vào file `index.html` để mở trực tiếp trên trình duyệt bất kỳ.

### Cách 2: Chạy qua Local Server
```bash
# Sử dụng Node.js npx serve
npx serve . -p 3000

# Hoặc dùng Python
python -m http.server 3000
```
Truy cập: [http://localhost:3000](http://localhost:3000)
